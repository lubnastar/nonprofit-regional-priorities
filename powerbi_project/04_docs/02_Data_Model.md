## Tables

| Table | Grain | Rows | Role |
|---|---|---|---|
| `dim_region` | Region | 13 | Conformed dimension: English and Arabic names, tile-map position, final priority group, baseline gap rank (sort key) |
| `dim_year` | Year | 18 | 2005-2022, with a transition-year flag for 2022. It serves as the date table: all data is annual, so a day-level calendar would add nothing. |
| `dim_org_type` | Type | 2 | Association / Foundation |
| `dim_sensitivity_test` | Test | 6 | The six tests of notebook 8.1 |
| `dim_scenario` | Scenario | 4 | **Disconnected** selector: the measures read it with `SELECTEDVALUE` |
| `fact_region_snapshot` | Region | 13 | Population 2022, social security 2022 and 2020-22 average, HIES 2023 income, spending and food share |
| `fact_population` | Region × year | 169 | Total and Saudi population 2010-2022 |
| `fact_social_security` | Region × year | 234 | Beneficiaries 2005-2022 |
| `fact_organizations` | Organization | 2,723 | Registry rows (surrogate `org_id`, because `reg_no` is not unique) |
| `fact_sensitivity_rank` | Region × test | 78 | Gap rank in each test (pre-computed in Python) |
| `fact_robustness` | Region | 13 | 1,000 random weightings + leave-one-out (pre-computed in Python) |
| `Weight SS`, `Weight Income`, `Weight Food` | Value | 6 each | What-if tables (`GENERATESERIES(0,5,1)`) for custom fragility weights; default weight 1 |
| `_Measures` | n/a | n/a | Home table of all measures, in display folders 1-8 |

## Relationships (10, all many-to-one, single direction)

| From (many) | To (one) |
|---|---|
| fact_region_snapshot[region_id] | dim_region[region_id] |
| fact_population[region_id] | dim_region[region_id] |
| fact_population[year] | dim_year[year] |
| fact_social_security[region_id] | dim_region[region_id] |
| fact_social_security[year] | dim_year[year] |
| fact_organizations[region_id] | dim_region[region_id] |
| fact_organizations[org_type_id] | dim_org_type[org_type_id] |
| fact_sensitivity_rank[region_id] | dim_region[region_id] |
| fact_sensitivity_rank[test_id] | dim_sensitivity_test[test_id] |
| fact_robustness[region_id] | dim_region[region_id] |

## Design choices

- **Measures, not calculated columns.** Every indicator, z-score, rank and gap is a DAX measure, so it reacts to the scenario slicer and the weights. The only calculated tables are the three what-if weight tables.
- **Relative to all 13 regions.** z-scores and ranks iterate `ALL(dim_region)`. Filtering the page to a few regions therefore never changes a region's score: it is always computed against all 13, as in the notebook.
- **Disconnected scenario table.** Switching scenario changes the formulas (social security basis, organization count), not the rows, so the table has no relationship.
- **Pre-computed robustness.** The six-test ranks, the 1,000 random weightings and leave-one-out need repeated re-standardisation. They come from the notebook's code (`build_model_data.py`) and are stored as facts.
- **Hidden technical columns.** Keys and raw numeric columns are hidden, so report authors use the measures.
- **Portable source.** Each query reads `DataFolder\<table>.csv` and falls back to an embedded copy when that folder is unreachable (see `04_Power_Query_M.md`).
