# Power Query (M)

Every table is loaded from the clean CSV files in `02_data/` through one text parameter, `DataFolder`, with an embedded fallback (below). Types are set with an explicit `en-US` culture so decimals parse the same on any Windows locale (the machine this was built on uses Arabic regional settings).

## Parameter

```powerquery
DataFolder = "C:\Users\lubna\OneDrive\سطح المكتب\projectsForMe\Lubna_submission\powerbi_project\02_data" meta [IsParameterQuery=true, Type="Text", IsParameterQueryRequired=true]
```

**Portable by design:** every query first tries `DataFolder`; if that folder is not reachable (the project was copied to another computer), it falls back to a compressed copy of the same CSV embedded in the query (`Embedded`, raw deflate + base64, generated by `build_semantic_model.py`). So the report refreshes anywhere without editing anything. To load edited CSVs from a new location: *Transform data > Edit parameters > DataFolder*, then *Refresh*.

## dim_region

One row per administrative region (13). Conformed dimension for every fact.

```powerquery
let
    // 1) read the clean CSV from 02_data; 2) if the folder is not reachable (project moved), use the embedded snapshot
    Embedded = "<base64 snapshot of dim_region.csv>",
    FileBinary = try Binary.Buffer(File.Contents(DataFolder & "\dim_region.csv")) otherwise Binary.Decompress(Binary.FromText(Embedded, BinaryEncoding.Base64), Compression.Deflate),
    Source = Csv.Document(FileBinary, [Delimiter = ",", Encoding = 65001, QuoteStyle = QuoteStyle.Csv]),
    PromotedHeaders = Table.PromoteHeaders(Source, [PromoteAllScalars = true]),
    ChangedTypes = Table.TransformColumnTypes(PromotedHeaders, {{"region_id", Int64.Type}, {"region_en", type text}, {"region_ar", type text}, {"tile_col", Int64.Type}, {"tile_row", Int64.Type}, {"priority_group", type text}, {"priority_group_order", Int64.Type}, {"baseline_gap_rank", Int64.Type}}, "en-US")
in
    ChangedTypes
```

## Why the cleaning itself is in Python, not M

The raw HIES file is a publication workbook (four separately laid-out sheets, one of them transposed, region names with embedded line breaks), and the notebook's cleaning carries assertions (Grand Total equals the sum of regions, every region name maps, no missing values). `01_scripts/build_model_data.py` re-runs that exact code and fails loudly if anything changes, then hands Power Query clean, typed, tidy CSVs. Power Query only types and loads, which keeps refreshes fast and the logic in one place.
